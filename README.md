## Welcome to the Companion Code Repository

If you've picked up this book, you're serious about going beyond the basics of Generative AI — and that's exactly the kind of reader we wrote this for. This repository contains all the code samples, Jupyter notebooks, and supporting assets that accompany each chapter, so you can follow along, experiment freely, and build confidence as you work through the material.

Every example here is designed to be run as-is, with clear instructions in the book walking you through what each piece of code does and why. We've used Jupyter notebooks throughout so you can step through the examples one cell at a time, observe the outputs, and tinker without fear.

## What's Inside

The book — and this repo — is organized into four progressive sections:

| Section | Chapters | Focus |
|---|---|---|
| **Foundational NLP** | 1 – 4 | NLP basics, NLTK, SpaCy, TextBlob, Scikit-Learn |
| **Advanced NLP Techniques** | 5 – 7 | Word2Vec, GluonNLP, Deep Learning, Topic Modelling |
| **LLM Architectures** | 8 – 9 | From NLP to LLMs, SageMaker HyperPod |
| **Generative AI Apps** | 10 – 14 | Bedrock Agents, Alexa, Knowledge Graphs, Amazon Q, Responsible AI |

Each chapter folder contains the notebooks and any data files you'll need for that chapter's exercises.

## Prerequisites

To get the most out of this repository, you'll want to have the following in place:

- **Python 3.x** with familiarity in writing and running scripts
- An **AWS account** with appropriate permissions for SageMaker, Bedrock, Lambda, and other services used in the book
- **Jupyter Notebook or JupyterLab** installed locally, or access to Amazon SageMaker Studio
- Basic familiarity with machine learning concepts like classification and regression will help, though we do our best to explain everything as we go

## Getting Started

Clone this repository to your local machine or SageMaker environment:

```bash
git clone https://github.com/OrangeAVA/Cutting-edge-Natural-Language-Processing-on-AWS-with-Python.git
cd Cutting-edge-Natural-Language-Processing-on-AWS-with-Python
```

Dependencies for each chapter are called out in the book. Where needed, you can install them with:

```bash
pip install -r requirements.txt
```
